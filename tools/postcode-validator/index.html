UK Postcode Validator

Check whether a UK postcode is correctly formatted, and optionally whether it's a real, in-use postcode.

Enter a valid postcode to check if it's real.

Validate a list

# Input Normalised Format Real postcode

Lists are capped at 500 postcodes per check.

Format checking runs entirely in your browser using the regular expressions from ideal-postcodes/postcode (MIT licensed) — nothing is sent anywhere for this part. "Real postcode" checks call postcodes.io, a free, open-source UK postcode API run by the same team; the postcodes you check are sent to that service to look up. A correctly formatted postcode isn't necessarily in use (it may never have been allocated, or may have been retired) — that's exactly what the "real postcode" check is for.
