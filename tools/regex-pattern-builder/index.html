Everything runs in your browser — the file or pasted text is never uploaded anywhere. "Per-position" mode is offered only when every line is the same length, and builds the pattern column by column (a literal character where a column never varies, a character class of only the characters actually seen where it does). "Charset range" mode instead finds the longest common prefix/suffix across all lines and allows a bounded-length run of the observed characters in between — the only option for variable-length data. Neither mode can know your intent beyond what's in the sample: if a column happened to only ever contain digits 1–3, that's what the pattern will require, even if 0 and 4–9 are valid in principle — widen the character class or length bounds by hand once you understand why a row failed.
