Digests

Worth knowing:

  • Everything runs locally in your browser — nothing you type or upload here is sent anywhere.
  • Text is hashed as UTF-8 bytes, exactly as typed, with no trailing newline added — this matches printf '%s' "text" | shasum, not echo "text" | shasum (which adds one).
  • MD5 and SHA-1 are cryptographically broken and shouldn't be relied on for security purposes (signatures, password storage, tamper-proofing) — they're included here purely for compatibility/checksum comparison against existing systems that still use them.
  • Keccak-256 is not the same as SHA3-256, despite the similar name and despite Ethereum tooling colloquially calling Keccak-256 "sha3" — NIST changed the padding when Keccak was standardised as SHA-3, so the two produce different digests for identical input. Both are provided since both are in common use.
  • MD5, the SHA-3 family, Keccak-256, and CRC-32 are hand-implemented in plain JavaScript (the browser has no built-in support for them) and verified against known test vectors — see hash-lib.test.js. SHA-1/256/384/512 use the browser's own built-in SubtleCrypto implementation. Very large files may take a noticeable moment, particularly for the hand-implemented algorithms.
