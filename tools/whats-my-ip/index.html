Public IP and network location are looked up via ipapi.co — unlike the other tools here, this one needs a third-party lookup, since a static page has no way to see its own visitor's IP address otherwise (this is exactly what any website's server logs would show automatically, permission-free). If it's blocked by an ad-blocker or privacy extension, or you're offline, that section will show an error instead. Network-based location is approximate (often city-level, sometimes off); precise location only appears if you click the button above and grant permission, and is never sent anywhere — it's read directly from your browser and shown only to you.
